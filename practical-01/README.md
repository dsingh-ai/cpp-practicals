# Practical 1 - C++ Basics

Reads marks of 3 subjects and shows the total, average, pass/fail and distinction.
Uses int/float variables, a `const`, arithmetic, relational and logical operators, and `cin`/`cout`.

## Run
```
g++ fundamentals.cpp -o fundamentals
./fundamentals
```

## Sample
```
Enter marks of 3 subjects: 78 85 92
Total = 255
Average = 85
Result: Pass
Grade: Distinction
```
